# CS50 SQL — Week 1: Packages

SQL problem set from [CS50's Introduction to Databases with SQL](https://cs50.harvard.edu/sql/).

## Topics

* Relational databases
* Primary and foreign keys
* JOINs
* Filtering and conditions
* NULL values
* Sorting and ordering
* Tracking records with timestamps
* SQLite

## Database

`packages.db` — a dataset containing information about packages, addresses, drivers, and delivery scans.
