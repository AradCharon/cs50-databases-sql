# CS50 SQL — Week 1: DESE

SQL problem set from [CS50's Introduction to Databases with SQL](https://cs50.harvard.edu/sql/).

## Topics

* Relational databases
* Primary and foreign keys
* JOINs
* Subqueries
* Aggregate functions
* Filtering and conditions
* GROUP BY and HAVING
* Sorting and ordering
* SQLite

## Database

`dese.db` — a dataset containing information about school districts, schools, graduation rates, expenditures, and staff evaluations.
